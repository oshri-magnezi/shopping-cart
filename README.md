# רשימת קניות | Shopping List

[![Deploy](https://github.com/oshri-magnezi/shopping-cart/actions/workflows/deploy.yml/badge.svg)](https://github.com/oshri-magnezi/shopping-cart/actions/workflows/deploy.yml)
[![Refresh prices](https://github.com/oshri-magnezi/shopping-cart/actions/workflows/prices.yml/badge.svg)](https://github.com/oshri-magnezi/shopping-cart/actions/workflows/prices.yml)

אתר לניהול רשימות קניות, השוואת מחירים בין רשתות השיווק ומעקב אחר ההוצאות. הרשימה וההיסטוריה נשמרות ב-`localStorage` של הדפדפן, כך שהן נשארות גם אחרי סגירת האתר.

## יכולות

- הוספת פריט לרשימה עם השלמה אוטומטית מתוך מחירוני הרשתות, ובחירת קטגוריה בחלון ייעודי (כולל יצירת קטגוריות משלכם ומחיקתן)
- **מוצרים לפי משקל** — מוצר שנמכר בתפזורת (מעדנייה, בשר, ירקות) נפתח אוטומטית עם תיבת משקל, ומראה בזמן אמת כמה הוא יוצא: `₪19.90 לק"ג · 500 גרם ≈ ₪9.95`
- עריכת פריט, שינוי כמות או משקל, ומחיקה
- סימון פריט כנרכש — מוצג עם קו חוצה
- **השוואת מחירים** בין רשתות השיווק לפי עיר, כולל סכום סופי לכל רשת ופירוט פר-פריט
- בסיום הרשימה מוזן סכום הקנייה, והקנייה נשמרת בהיסטוריה
- היסטוריית קניות עם סך ההוצאה, ממוצע לקנייה, וגרף מגמת הוצאה
- ממשק בעברית ובאנגלית, מצב אור וחושך, ואפשרות התקנה כאפליקציה (PWA) עם עבודה גם ללא רשת

## איך עובדת השוואת המחירים

הבוט שב-[`bot/`](bot/) קורא את קבצי שקיפות המחירים הרשמיים של הרשתות ומייצר קטלוג לכל עיר תחת `public/`. האתר מוריד רק את הקטלוג של העיר שנבחרה ומבצע את ההתאמה בעצמו, כך שכל פריט שמקלידים נבדק — ולא רק פריטים שתומחרו מראש.

**זיהוי מוצרים** נשען על ברקוד: אותו ברקוד הוא אותו מוצר בכל הרשתות, ולכן מוצר שנבחר מההשלמה האוטומטית מסומן "מזוהה מדויק" ואינו מנוחש. קודים קצרים מ-8 ספרות הם קודי PLU פנימיים שכל רשת מקצה בעצמה, ולכן אינם משמשים לזיהוי בין-רשתי. פריט שהוקלד ביד נופל להתאמה טקסטואלית בעברית.

**מוצרים שקילים** מסומנים בקטלוג, והמחיר שלהם הוא לקילוגרם. השוואה כופה התאמה של יחידת מכירה — מוצר לק"ג מותאם רק למוצרים לק"ג — אחרת עגבניה בתפזורת ב-₪6.90 לק"ג הייתה נראית יקרה מאריזת קילו ב-₪12.90.

המחירים מתרעננים אוטומטית כל לילה דרך [`.github/workflows/prices.yml`](.github/workflows/prices.yml). אפשר גם להריץ ידנית מלשונית Actions.

## הרצה מקומית

```bash
npm install
npm run dev
```

בדיקות: `npm test`. בנייה לפרודקשן: `npm run build`, ותצוגה מקדימה: `npm run preview`.

לרענון המחירונים מקומית, ראו את ה-README של הבוט.

## פריסה

הפריסה מתבצעת אוטומטית ל-GitHub Pages בכל דחיפה ל-`main`, דרך [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). הבדיקות רצות לפני הבנייה, וכישלון בהן עוצר את הפריסה.

לפני הפריסה הראשונה יש להגדיר בהגדרות המאגר: **Settings → Pages → Source: GitHub Actions**.

אם שם המאגר שונה מ-`shopping-cart`, יש לעדכן בהתאם את `base` בקובץ `vite.config.js`.

## מבנה הפרויקט

```
src/
├── components/   רכיבי ממשק (חלון בחירת קטגוריה, שורת פריט, גרף, חלונות אישור)
├── context/      ניהול מצב: נתוני האפליקציה, הקטלוג, והגדרות השפה והתצוגה
├── i18n/         מילוני עברית ואנגלית
├── pages/        עמוד הרשימה, ההיסטוריה וההשוואה
├── styles/       טוקנים של מערכת העיצוב וסגנונות גלובליים
└── utils/        אחסון מקומי, התאמת עברית, אינדוקס הקטלוג ועיצוב תאריכים וסכומים

public/           הקטלוגים שהבוט מייצר, המניפסט וה-service worker
bot/              בוט המחירים — פרויקט npm עצמאי
```

`src/utils/hebrew.js` הוא המקור היחיד לכללי ההתאמה, והבוט מחזיק עותק זהה שלו ב-`bot/src/match/hebrew.js`. בדיקה אוכפת שהשניים זהים בייט-לבייט; אם עורכים אחד, יש להעתיק לשני.
