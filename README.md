# רשימת קניות | Shopping List

אתר לניהול רשימות קניות ומעקב אחר הוצאות. כל הנתונים נשמרים ב-`localStorage` של הדפדפן, כך שהרשימה וההיסטוריה נשמרות גם אחרי סגירת האתר.

## יכולות

- הוספת פריט לרשימה, ובחירת קטגוריה עבורו בחלון ייעודי (ירקות ופירות, מוצרי חלב, שימורים ועוד — כולל יצירת קטגוריה משלכם)
- עריכת פריט, שינוי כמות ומחיקה
- סימון פריט כנרכש — הפריט מוצג עם קו חוצה
- תאריך ושעה לכל רשימה
- בסיום הרשימה מוזן סכום הקנייה בשקלים, והקנייה נשמרת בהיסטוריה
- היסטוריית קניות עם סך ההוצאה, ממוצע לקנייה ופירוט הפריטים בכל קנייה
- ממשק בעברית ובאנגלית, ומצב אור וחושך

## הרצה מקומית

```bash
npm install
npm run dev
```

בנייה לפרודקשן: `npm run build`, ותצוגה מקדימה של הבנייה: `npm run preview`.

## פריסה

הפריסה מתבצעת אוטומטית ל-GitHub Pages בכל דחיפה ל-`main`, דרך ה-workflow שב-`.github/workflows/deploy.yml`.

לפני הפריסה הראשונה יש להגדיר בהגדרות המאגר: **Settings → Pages → Source: GitHub Actions**.

אם שם המאגר שונה מ-`shopping-cart`, יש לעדכן בהתאם את `base` בקובץ `vite.config.js`.

## מבנה הפרויקט

```
src/
├── components/   רכיבי ממשק (חלון בחירת קטגוריה, שורת פריט, חלונות אישור)
├── context/      ניהול מצב: נתוני האפליקציה והגדרות השפה והתצוגה
├── i18n/         מילוני עברית ואנגלית
├── pages/        עמוד הרשימה ועמוד ההיסטוריה
├── styles/       טוקנים של מערכת העיצוב וסגנונות גלובליים
└── utils/        אחסון מקומי, קטגוריות ועיצוב תאריכים וסכומים
```
